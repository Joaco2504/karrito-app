# Assets de marca de Karrito

Colocá aquí los archivos PNG con fondo transparente del logo horizontal (ícono + nombre):
- `logo_light.png`: versión para modo claro (tinta oscura sobre fondo `#FDF7FF`).
- `logo_dark.png`: versión para modo oscuro (tinta clara sobre fondo `#12111A`).

Tamaño recomendado: altura 96 px (3x), relación horizontal aprox. 3.5:1.
Mientras estos archivos no existan, `KarritoBrandLogo` muestra automáticamente el ícono vectorial y el nombre "Karrito".
